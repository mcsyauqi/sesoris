Highlight Implementasi

Exit-Intent Detection

Menggunakan document.addEventListener('mouseleave') dengan filter e.clientY <= 5 untuk mendeteksi mouse yang keluar dari viewport bagian atas — indikator user akan pindah tab atau close. Fallback timer 45 detik untuk mobile users.

Cooldown: Setelah popup ditampilkan (baik subscribe maupun dismiss), disimpan timestamp ke localStorage. Popup tidak akan muncul lagi dalam 7 hari ke depan.

Graceful Degradation

API route akan tetap return HTTP 200 success meskipun BREVO_API_KEY belum di-set. Ini memastikan form tidak error di production sementara setup Brevo selesai. Subscriber akan di-log ke console saja sampai API key aktif.

⚠️ Diperlukan Setup Lanjutan: Sistem sudah deployed dan fungsional, tapi email belum benar-benar terkirim hingga BREVO_API_KEY di-set di Vercel Environment Variables. Estimasi waktu setup: 15 menit.
